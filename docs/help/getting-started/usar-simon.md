# Usar Simón para consultar sobre VetZen

## Cuándo usarlo

Usá Simón cuando necesitás ayuda para realizar una acción disponible en VetZen.
Por ejemplo, podés preguntar cómo registrar una mascota o consultar una
solicitud de atención.

## Cómo hacerlo

1. En el menú principal, abrí **Simón**.
2. Escribí una pregunta sobre cómo usar VetZen.
3. Enviá la pregunta y esperá la respuesta.
4. Revisá las fuentes que acompañan la respuesta si necesitás identificar la
   guía utilizada.

## Importante

Simón responde usando la documentación disponible de VetZen. No realiza
diagnósticos, no recomienda fármacos ni brinda orientación veterinaria. Si no
encuentra información suficiente, te lo indicará.

## Qué sucede después

La conversación se conserva solo mientras mantenés abierta la página. Al salir
o recargar, las preguntas y respuestas anteriores dejan de mostrarse.
