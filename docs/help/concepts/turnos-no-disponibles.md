# Turnos y agenda no disponibles actualmente

VetZen no dispone actualmente de una función de turnos, agenda, reservas,
reprogramación ni selección de horarios.

## Alternativa disponible

Un cliente puede solicitar atención para un servicio disponible y una mascota
propia. Esa solicitud no reserva un turno ni selecciona un tratamiento.
