La feature debe incluir:

- Navegación por rol.
- Grupos del sidebar.
- Vocabulario visible definitivo.
- Menú de cuenta.
- Navegación responsive.
- Estado activo en rutas anidadas.
- Componente base `PageHeader`.
- Breadcrumbs base.
- Aplicación inicial de `PageHeader` solamente a las vistas principales.
- Accesibilidad, responsive, pruebas y criterios de aceptación.

- Datos nuevos de dashboards.
- Rediseño de tablas.
- Nuevos filtros o endpoints.
- Historia clínica.
- Verificación de correo.
- Tratamientos o sesiones.
- Landing o autenticación.
- Cambios de base de datos.
- Implementación de código.

La documentación debe especificar objetivo, situación actual, alcance, fuera de alcance, navegación exacta por rol, componentes afectados, comportamiento desktop/móvil, requisitos de accesibilidad, riesgos, plan de implementación y criterios de aceptación.
